## 已修复

1. **原价 IMD 支付缺少自动授权。** 此前只有换币或附加支持款才经过付款准备流程，新钱包选择原价时会失败，Robinhood 还会要求用户手动运行 `wallet approve`。现在所有付款共用 `fundOrder`：先检查余额、预算和手续费，在一次确认后只授权本次所需额度。已有足额授权不再发送授权交易。两条链均有回归测试，覆盖取消确认、精确金额和恢复不重复付款。
2. **付款准备期间的状态和钱包变化。** 只有真正签署第一笔交易后才将订单标记为 `funding`；准备失败且没有签名的请求仍可取消。每笔授权、换币或支持转账签名前，重新确认钱包和本地取消状态，防止等待 RPC 时另一终端的操作被覆盖。测试覆盖估算期间取消请求和更换钱包，均不广播。
3. **继续修改已有任务被空技能目录阻断。** `same` 本身是合法的继续项目路由，现在计入可执行路线；没有其他可运行技能时仍能继续原项目。新建任务仍需要可运行技能。
4. 修正 README 中过时的钱包授权快捷键、Lock 操作和手动授权说明。
